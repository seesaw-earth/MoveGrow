# Security and privacy reports

MoveGrow processes highly sensitive family video content locally. Please do not include baby videos, medical records, credentials, or other private data in a public GitHub issue.

For ordinary bugs and feature requests, use the public issue tracker with synthetic examples only.

Until a dedicated private security contact is published, do not disclose an unpatched vulnerability containing exploit details in a public issue. The maintainer should add a private security-reporting channel before broad public distribution.
