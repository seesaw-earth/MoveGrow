# Contributing to MoveGrow

Thank you for your interest in MoveGrow.

## Privacy first

Do not submit baby videos, medical records, protected health information, or other sensitive personal information in issues, pull requests, test fixtures, screenshots, or sample data. Use synthetic or explicitly non-sensitive test material.

## Development

1. Use a current Apple-supported Xcode version for App Store builds.
2. Open `MoveGrow.xcodeproj`.
3. Let Xcode resolve the pinned `UltralyticsYOLO` package.
4. Run `python3 Checks/static-check.py`.
5. On macOS, run `bash Checks/check-on-mac.sh` before submitting a pull request.
