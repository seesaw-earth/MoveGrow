支持

请发邮件至 ziqing.shi@icloud.com；如需反馈错误或提出功能建议，也可以在 GitHub 上提交问题反馈。

请不要在 GitHub 上公开的问题反馈中附上宝宝的视频、病历或其他私密的健康信息。

反馈问题时，请提供

  • MoveGrow 的版本（App 中的“设置 → 关于 MoveGrow”）；
  • 你的 iPhone 机型和 iOS 版本；
  • 你预期的结果，以及实际发生了什么；
  • 如需配图，请使用不含隐私内容的示例。

常见问题

分析很慢或已暂停

相机打开时分析会暂停，在较旧的 iPhone 上也会慢一些。请保持 App 打开；在 iOS 26 上也可以让它在后台继续。

视频没有日期

有些 App 会去掉拍摄日期。打开视频，轻点“添加拍摄日期”：可以选择具体日期、宝宝出生后的天数，或者大概时间。

怎么切换语言？

在 App 中前往“设置 → 语言”，切换会立即生效。

怎么保留视频？

换手机或删除 App 前请先导出：打开视频，轻点分享按钮导出带图表的 MP4；或者打开选项菜单，选择“原始视频”。

以前的视频正在重新分析

MoveGrow 现在以三维方式分析。这次更新之前分析过的视频会自动从头重新分析。你的备注、日期和里程碑都会保留。

医疗问题

MoveGrow 不提供医学诊断或治疗建议。如对孩子的发育或健康有任何担心，请咨询医疗专业人员。
