MoveGrow Support

For bug reports, feature requests, or help using MoveGrow, open an issue in the MoveGrow GitHub repository.

Please do not attach baby videos, medical records, private health information, or other sensitive personal information to a public GitHub issue.

Before reporting a problem

  • Include the MoveGrow version number.
  • Include the iPhone model and iOS version.
  • Describe what you expected and what happened.
  • Use a synthetic or non-sensitive example if an image is necessary.

Medical questions

MoveGrow does not provide medical diagnosis or treatment advice. For concerns about a child's development or health, contact an appropriate healthcare professional.
